# VitePress Documentation

This directory contains auto-generated VitePress documentation for the OpenRemote Rails API.

## Setup

```bash
# Install VitePress dependencies
cd docs
npm install
```

## Development

```bash
# Start VitePress dev server (from project root)
npm run docs:dev

# Or from docs directory
cd docs && npm run dev
```

## Building

```bash
# Build for production (from project root)
npm run docs:build

# Or from docs directory
cd docs && npm run build
```

## GitHub Pages Deployment

Documentation is automatically deployed to GitHub Pages via GitHub Actions when:

- Changes are pushed to `main` branch affecting:
  - `docs/**` files
  - `app/**` files (components)
  - `spec/**` files (tests)
  - Documentation generator (`lib/tasks/docs_generator.rb`)

The workflow:
1. Generates documentation from Rails components and tests
2. Builds VitePress site
3. Deploys to `gh-pages` branch
4. Serves at: `https://<username>.github.io/<repository-name>/`

### Manual Deployment

You can also trigger deployment manually:
1. Go to Actions tab in GitHub
2. Select "Deploy Documentation" workflow
3. Click "Run workflow"

## Auto-Discovery

The documentation is automatically generated by scanning:

- `app/models/**/*.rb` - ActiveRecord models
- `app/controllers/**/*.rb` - ActionController classes
- `app/services/**/*.rb` - Service objects
- `app/jobs/**/*.rb` - ActiveJob classes
- `app/models/concerns/**/*.rb` - Shared concerns

And extracting examples from:

- `spec/**/*_spec.rb` - RSpec test files

## Regenerating Documentation

```bash
# Generate from components and tests
bundle exec rake docs:from_tests

# Or automatically after running tests
bundle exec rspec  # Auto-generates if GENERATE_DOCS != "false"
```

## Configuration

The VitePress configuration is auto-generated in `.vitepress/config.js` based on discovered components. The sidebar navigation is automatically organized by component type (Models, Controllers, Services, Jobs, Concerns).

### Base Path

- **Local development**: Base path is `/` (root)
- **GitHub Pages**: Base path is `/<repository-name>/` (automatically configured)
