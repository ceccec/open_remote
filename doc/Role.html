Overview

Role model for Rolify. Represents user roles that can be assigned to users. Supports resource-scoped roles (e.g., admin of a specific asset).

.find_or_create_by_name(role_name, resource: nil) ⇒ Role

Find or create a role by name.

Examples:

Create a global admin role

admin_role = Role.find_or_create_by_name("admin")

Create a resource-scoped manager role

asset = Asset.find_by(name: "Main Building")
manager_role = Role.find_or_create_by_name("manager", resource: asset)

Parameters:

  • role_name (String) —

    name of the role (e.g., “admin”, “manager”, “viewer”)

  • resource (ActiveRecord::Base, nil) (defaults to: nil) —

    optional resource to scope the role

Returns:

  • (Role) —

    the found or created role

def rails_admin_label

  label += " - #{resource.name}" if resource.respond_to?(:name)
